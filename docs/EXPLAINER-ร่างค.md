## 0. ภาพรวม — จาก 16 ข้อ เหลือ 5 ตัวชี้วัด

สิ่งที่หายไปไม่ใช่ "คำถาม" แต่เป็น "ช่องให้คะแนนแยกกัน" — แบบฟอร์มยังถามเท่าเดิม แต่คำตอบหลายข้อถูกรวมเป็นดัชนีเดียวก่อนคิดคะแนน

| เกณฑ์เดิม | น้ำหนักเดิม | กลายเป็นอะไรในร่าง ค | น้ำหนักใหม่ |

**ผลรวม:** ผ่านเกณฑ์ตรวจรับรายข้อ **5 จาก 5 ข้อ** ขณะที่เกณฑ์เดิมผ่าน **5 จาก 16 ข้อ** เมื่อวัดด้วยเกณฑ์เดียวกัน (ผ่าน: ข้อ 2 ชายแดน · 7 แหล่งน้ำ · 9 โทรศัพท์ · 11 % ชาติพันธุ์ · 16 ประกาศคลัง) · SD ของคะแนนรวมเพิ่มจาก 9.07 เป็น 19.90 · D ต่ำสุดในชุดเพิ่มจาก 0.04 เป็น 0.33

## 1. ข้อเสนอ 2 — ความสูง: ตัดคะแนนฐาน ไล่ระดับถึงเปอร์เซ็นไทล์ที่ 90 ของจริง

### เดิมทำอย่างไร

```
ถ้า ความสูง ≥ 500 ม. หรือ ความสูง ≥ ค่าเฉลี่ยของเส้นทาง
    คะแนน = 15 + min(ความสูง, 500) × 15/500
มิฉะนั้น
    คะแนน = 0
```

สูตรนี้มีปัญหาซ้อนกันสองชั้น

**ชั้นที่หนึ่ง — คะแนนฐาน 15** ทันทีที่ผ่านด่าน โรงเรียนได้ 15 คะแนนฟรีจาก 30 โดยไม่ต้องสูงกว่าใคร

**ชั้นที่สอง — เพดานที่ 500 ม.** ส่วนที่ไล่ระดับได้จริงมีแค่ช่วง 0–500 ม. แต่โรงเรียนที่ผ่านด่านย่อมสูง ≥ 500 ม. อยู่แล้ว จึงชนเพดานทันที ผลคือ **โรงเรียน 87.6% ได้ 30 เต็ม** ไม่ว่าจะอยู่ที่ 500 ม. หรือ 1,819 ม.

ตัวเลขยืนยัน: อำนาจจำแนก D = 0.04 (ค่าที่ยอมรับได้คือ ≥ 0.20) · สหสัมพันธ์กับคะแนนข้ออื่น r = 0.03 แปลว่าข้อที่กินน้ำหนัก 30 คะแนนนี้แทบไม่มีความสัมพันธ์กับความลำบากที่ข้ออื่นวัดได้เลย

### ใหม่ทำอย่างไร

```
คะแนน = clamp((ความสูง − 300) ÷ (1350 − 300), 0, 1) × 24
```

- **จุดเริ่ม 300 ม.** ไม่ใช่ 500 ม. เพราะร่าง ค เลือกไม่ตัดโรงเรียนที่ต่ำกว่า 500 ม. ออก (ต่างจากร่าง ก) จึงต้องมีที่ให้โรงเรียนช่วง 300–500 ม. ได้คะแนนบ้าง
- **จุดเต็ม 1,350 ม.** คือเปอร์เซ็นไทล์ที่ 90 ของความสูงจริงในประชากร ไม่ใช่เลขกลมที่ตั้งลอย ๆ — เลือกแบบนี้เพื่อให้ 90% ของโรงเรียนอยู่ในช่วงที่คะแนนยังไล่ระดับได้ มีเพียง 10% บนสุดที่ชนเพดาน
- **ไม่มีคะแนนฐาน** โรงเรียนที่ 300 ม. ได้ 0 คะแนนจากข้อนี้ ไม่ใช่ 15

### เทียบกันตรง ๆ

| ความสูงจริง | คะแนนเดิม (เต็ม 30) | คะแนนใหม่ (เต็ม 24) |
|---:|---:|---:|
| 300 ม. | ไม่ผ่านด่าน = 0 | 0.00 |
| 400 ม. | ไม่ผ่านด่าน = 0 | 2.29 |
| 500 ม. | **30.00** | 4.57 |
| 600 ม. | **30.00** | 6.86 |
| 800 ม. | **30.00** | 11.43 |
| 1,000 ม. | **30.00** | 16.00 |
| 1,350 ม. | **30.00** | 24.00 |
| 1,819 ม. (สูงสุดในฐาน) | **30.00** | 24.00 |

คอลัมน์กลางคือหัวใจของปัญหา — เกณฑ์เดิมมองว่าโรงเรียนที่ 500 ม. กับ 1,819 ม. ลำบากเท่ากันทุกประการ

### ผลที่เกิดขึ้น

ข้อนี้เปลี่ยนจาก D = 0.04 เป็น **D = 0.52** และ item–rest r จาก 0.03 เป็น 0.43 คือกลายเป็นตัวชี้วัดที่ทำงานจริง

**แต่มีผลข้างเคียงที่ต้องรู้:** โรงเรียน 198 แห่งที่รายงานความสูง "500 ม. พอดี" มีคะแนนรวมเฉลี่ยลดจาก 60.21 เหลือ 34.38 เพราะเดิมได้ 30 เต็ม ตอนนี้ได้ 4.57 — กลุ่มนี้คือกลุ่มที่การกระจุกตัวผิดปกติชี้ว่าตัวเลขอาจถูกกรอกให้พอดีเกณฑ์ **ทางแก้ที่ถูกต้องคือล็อกค่าจาก GIS ตามข้อเสนอ 4 ไม่ใช่ปล่อยให้สูตรใหม่ลงโทษไปโดยที่ยังไม่รู้ว่าความสูงจริงเท่าไร** — ควรวัดค่าจริงของกลุ่มนี้ใหม่ก่อนบังคับใช้

## 2. ข้อเสนอ 5 — ตัด "ประกาศกระทรวงการคลัง" ออกจากคะแนน

### ทำไมต้องตัด ทั้งที่มันเป็นข้อที่จำแนกได้ดีที่สุด

ข้อ 16 มีสถิติดีที่สุดในเกณฑ์เดิมทุกด้าน — D = 0.87 สูงสุด · ส่วนแบ่งความแปรปรวนของคะแนนรวม 17.9% สูงสุด · ถ้าดูตัวเลขอย่างเดียวควรเพิ่มน้ำหนักด้วยซ้ำ

ปัญหาอยู่ที่ **ที่มาของอำนาจจำแนกนั้น** — คำถามคือ "เป็นโรงเรียนพื้นที่พิเศษตามประกาศกระทรวงการคลังหรือไม่" ซึ่งเป็น *ผลของการตัดสินใจครั้งก่อน* ไม่ใช่การวัดสภาพความลำบากในปัจจุบัน

กลไกที่เกิดขึ้นคือวงจรย้อนกลับ

```
เคยได้รับการประกาศ → ได้ 5 คะแนนในเกณฑ์นี้ → คะแนนรวมสูง
   → ผ่านการคัดกรอง → ได้รับการประกาศต่อ → ได้ 5 คะแนนอีก …
```

เกณฑ์ที่ให้น้ำหนักกับข้อนี้มาก ๆ จึงไม่ได้ตรวจสอบว่าโรงเรียนลำบากจริงหรือไม่ แต่กำลัง **รับรองการตัดสินใจของตัวเองในอดีต** ซึ่งทำให้ความผิดพลาดในรอบก่อน ๆ ถูกส่งต่อไปเรื่อย ๆ โดยไม่มีใครตรวจพบ

### แล้วเอาไปใช้ทำอะไรแทน

เสนอให้ใช้เป็น **ตัวสอบทานผล (validation)** — หลังคำนวณคะแนนด้วยเกณฑ์ใหม่แล้ว นำผลไปเทียบกับรายชื่อตามประกาศคลัง

- โรงเรียนที่ **เกณฑ์ใหม่ให้คะแนนสูงแต่ไม่อยู่ในประกาศ** → ควรตรวจว่าตกหล่นจากประกาศเดิมหรือไม่
- โรงเรียนที่ **อยู่ในประกาศแต่เกณฑ์ใหม่ให้คะแนนต่ำ** → ควรตรวจว่าสภาพเปลี่ยนไปแล้ว หรือเกณฑ์ใหม่มองข้ามปัจจัยบางอย่าง

วิธีนี้ได้ประโยชน์จากข้อมูลเดิมโดยไม่สร้างวงจรย้อนกลับ และยังใช้เป็นเครื่องมือตรวจจับข้อผิดพลาดของเกณฑ์ใหม่ได้ด้วย

## 3. ข้อเสนอ 6 — ยุบสาธารณูปโภค 4 ข้อเป็นดัชนีความรุนแรงเดียว

### ปัญหาของการให้คะแนนแยก 4 ข้อ

ข้อ 8 ไฟฟ้า · ข้อ 9 โทรศัพท์ · ข้อ 10 อินเทอร์เน็ต สหสัมพันธ์กันเอง **0.58–0.68** ค่าระดับนี้แปลว่าทั้งสามข้อกำลังวัดสิ่งเดียวกัน คือ *ระดับการเข้าถึงโครงสร้างพื้นฐานของหมู่บ้านที่โรงเรียนตั้งอยู่* — หมู่บ้านที่ไฟฟ้าเข้าไม่ถึงก็มักไม่มีสัญญาณโทรศัพท์และไม่มีอินเทอร์เน็ตด้วย

การให้คะแนนแยกกันจึงเท่ากับ **นับความลำบากเดียวซ้ำ 3 ครั้ง** ทำให้โรงเรียนที่ขาดแคลนครบทุกด้านได้เปรียบเกินกว่าที่ควรเป็นจริง

### ทางที่ลองแล้วไม่ได้ผล

ตอนแรกออกแบบเป็น **การนับจำนวนด้านที่ขาดแคลน** (0–4 ด้าน) ซึ่งฟังดูตรงไปตรงมา แต่พอคำนวณกับข้อมูลจริงพบว่ากระจุกอย่างหนัก

```
0 ด้าน  8%    1 ด้าน  73%    2 ด้าน  11%    3 ด้าน  3%    4 ด้าน  4%
```

สาเหตุคือ 91.5% ของโรงเรียนใช้น้ำที่ไม่ใช่ประปา จึงติดสัญญาณ "ขาดแคลนน้ำ" เหมือนกันหมด ดัชนีเลยกลายเป็นค่าคงที่ที่ 1 — แก้ปัญหาเดิมไม่ได้เลย

### สูตรที่ใช้จริง — ถ่วงน้ำหนักตามระดับความขาดแคลน

```
น้ำ      ธรรมชาติล้วน (ประปาภูเขา/ลำธาร) = 2 · บ่อ/สระ/บาดาล = 1 · ประปา = 0
ไฟฟ้า    ต้องพึ่งพลังงานทางเลือก = 2 · ไฟฟ้าส่วนภูมิภาค = 0
โทรศัพท์  ไม่มีสัญญาณ = 3 · ได้เฉพาะดาวเทียม = 2 · โทรศัพท์เคลื่อนที่ = 1 · พื้นฐาน = 0
เน็ต     ไม่มีเครือข่าย = 3 · ได้เฉพาะดาวเทียม = 2 · ไร้สาย = 1 · Fiber/Leased = 0

infraSeverity = ผลรวม (0–10)
คะแนน = clamp(infraSeverity ÷ 8, 0, 1) × 22
```

หลักคิดของการถ่วงน้ำหนัก: การไม่มีสัญญาณโทรศัพท์เลย (กระทบความปลอดภัยและการติดต่อฉุกเฉิน) รุนแรงกว่าการใช้น้ำจากลำธาร จึงให้ 3 กับ 2 ตามลำดับ

### ผลที่ได้

```
0:1%  1:7%  2:18%  3:32%  4:20%  5:5%  6:7%  7:1%  8:1%  9:2%  10:4%
```

ไม่มีช่วงไหนเกิน 32% — ดัชนีนี้แยกโรงเรียนออกจากกันได้จริง ให้ D = 0.33 และ item–rest r = 0.42

## 4. ข้อเสนอ 7 — ใช้ "ตัวเลือกที่ลำบากที่สุดที่เลือกไว้" และบังคับคุณสมบัติ monotonicity

### ข้อบกพร่องของเกณฑ์เดิม

ข้อ 7–10 ให้เลือกได้หลายตัวเลือก แต่สูตรเดิมคิดคะแนนจาก **id ที่มีค่าสูงสุด** ที่เลือกไว้ ปัญหาคือตัวเลือกเรียงจาก "ลำบากที่สุด" (id 1) ไป "สะดวกที่สุด" (id สูง) การหยิบ id สูงสุดจึงเท่ากับ **หยิบตัวเลือกที่ให้คะแนนต่ำที่สุด**

ผลคือยิ่งกรอกครบตามความจริง ยิ่งเสียคะแนน พบ **1,024 ครั้ง** ในสี่ข้อรวมกัน (แหล่งน้ำ 320 · ไฟฟ้า 93 · โทรศัพท์ 201 · อินเทอร์เน็ต 410)

**กรณีที่ชัดที่สุด — โรงเรียน sc_id 1042520183 จังหวัดเลย นักเรียน 14 คน**

โรงเรียนนี้กรอกว่ามีทั้งพลังงานทางเลือก (id 1) และไฟฟ้าส่วนภูมิภาค (id 2) สูตรเดิมหยิบ id 2 มาคิด จึงได้ **0 คะแนน** จากข้อไฟฟ้า เท่ากับโรงเรียนที่มีไฟฟ้าส่วนภูมิภาคอย่างเดียว ทั้งที่รายงานว่าต้องพึ่งพลังงานทางเลือกด้วย — ข้อมูลที่กรอกเพิ่มมาไม่ได้ช่วยอะไรเลย ซ้ำยังทำให้ได้คะแนนเท่าคนที่สภาพดีกว่า

เกณฑ์แบบนี้สอนให้คนกรอกไม่ครบ

### สิ่งที่ร่าง ค ทำ

ทุกดัชนีอ่านค่าด้วย `minOfCsv` คือ **หยิบ id ต่ำสุด = ตัวเลือกที่ลำบากที่สุดที่โรงเรียนเลือกไว้** ดังนั้นการเพิ่มข้อมูลที่เป็นจริงจะทำให้คะแนนเพิ่มขึ้นหรือเท่าเดิมเสมอ ไม่มีทางลดลง

โรงเรียนเดียวกันในร่าง ค ได้ `infraSeverity = 6` (น้ำธรรมชาติ 2 + พลังงานทางเลือก 2 + โทรศัพท์มือถือเท่านั้น 1 + เน็ตไร้สาย 1) = **16.5 จาก 22 คะแนน**

```

        → ไม่มีอินเทอร์เน็ต → ใช้น้ำธรรมชาติ) แล้วยืนยันว่าค่าดัชนีไม่ลดลงเลย
        และสูตร band/linear ไม่ลดลงเมื่อค่าตัวแปรเพิ่มขึ้น
```

ถ้าใครเขียนสูตรใหม่ที่ละเมิดคุณสมบัตินี้ในอนาคต `npm test` จะฟ้องทันที

## 5. ข้อเสนอ 8 — ยุบข้อที่พื้นตัน/เพดานตันเป็นดัชนีที่แปรผันจริง

### ทำไมการปรับน้ำหนักถึงแก้ไม่ได้

สามข้อด้านการเดินทางของเกณฑ์เดิมมีปัญหาคนละแบบแต่รากเดียวกัน

| ข้อ | อาการ | สาเหตุ |
|---|---|---|
| 4 ถนนรถสองล้อไปไม่ได้ | 87.2% ได้ 0 คะแนน (พื้นตัน) | โรงเรียนส่วนใหญ่ไม่มีเส้นทางแบบนั้น |
| 6 ขนส่งสาธารณะ | 79.3% ได้เต็ม (เพดานตัน) | โรงเรียนส่วนใหญ่ตอบว่า "ไม่มีรถประจำทาง" เหมือนกันหมด |
| 5 ระยะทางถึงศาลากลาง | 74.7% ชนเพดาน 80 กม. | เพดานต่ำกว่ามัธยฐานจริง (106 กม.) |

ไม่ว่าจะให้น้ำหนักเท่าไร ข้อที่คนตอบเหมือนกัน 80–90% ก็ยังแยกใครไม่ได้อยู่ดี **เพราะปัญหาอยู่ที่ตัวแปร ไม่ใช่ที่น้ำหนัก** การเพิ่มน้ำหนักให้ข้อที่ทุกคนได้เท่ากันมีผลเดียวคือบวกค่าคงที่ให้ทุกคนเพิ่มขึ้น

### สูตรที่ใช้จริง

```
ถนนที่รถสองล้อไปไม่ได้   > 5 กม. = 3 · 2–5 กม. = 2 · > 0 = 1 · ไม่มี = 0
ขนส่งสาธารณะ             ไม่มีรถประจำทาง = 2 · ≤ 2 เที่ยว/วัน = 1 · มากกว่านั้น = 0
ระยะทางถึงศาลากลาง       ≥ 184 กม. (P90) = 3 · ≥ 146 (P75) = 2 · ≥ 106 (P50) = 1 · ต่ำกว่า = 0

accessSeverity = ผลรวม (0–8)
คะแนน = clamp(accessSeverity ÷ 6, 0, 1) × 20
```

จุดตัดของระยะทางใช้เปอร์เซ็นไทล์จริงของประชากร (P50/P75/P90) แทนตัวเลขกลม เพื่อให้แต่ละระดับมีคนอยู่จริงในสัดส่วนที่ใกล้เคียงกัน

### ผลที่ได้

```
0:3%  1:9%  2:41%  3:19%  4:12%  5:9%  6:2%  7:2%  8:3%
```

จากสามข้อที่แยกกันแล้วใช้ไม่ได้เลย กลายเป็นดัชนีเดียวที่ให้ D = 0.36 และ item–rest r = 0.43

**ข้อสังเกตที่ควรรู้:** ค่า 2 ยังหนาแน่นที่ 41% เพราะโรงเรียนจำนวนมากมีสองสัญญาณพอดี (ไม่มีรถประจำทาง + ระยะทางเกินมัธยฐาน) ถ้าต้องการกระจายมากกว่านี้ ต้องเพิ่มสัญญาณย่อยหรือปรับจุดตัดของระยะทาง — ทำได้โดยแก้ไฟล์ JSON แล้วรัน `npm run legacy:simulate` ดูผลทันที

## 6. ข้อเสนอ 9 — ตัวชี้วัดที่นับตัวนักเรียนใช้ร้อยละทุกข้อ

### ความไม่สอดคล้องของเกณฑ์เดิม

| ข้อ | เก็บเป็น | คิดคะแนนเป็น |
|---|---|---|
| 13 นักเรียนยากจน | จำนวนคน | **ร้อยละ** ของนักเรียนทั้งหมด (เพดาน 50%) |
| 14 นักเรียนพักนอน | จำนวนคน | **จำนวนคน** ตรง ๆ (เพดาน 50 คน) |

สองข้อนี้อยู่กลุ่มตัวชี้วัดผู้เรียนเหมือนกัน แต่ใช้ฐานคนละแบบ ผลคือโรงเรียน 60 คนที่นักเรียนพักนอนทั้งโรงเรียน ได้คะแนนเท่ากับโรงเรียน 800 คนที่มีนักเรียนพักนอน 50 คน ทั้งที่ภาระต่างกันมาก รวมข้อที่ไม่ปรับตามขนาดโรงเรียน 15 คะแนน

### สิ่งที่ร่าง ค ทำ

ตัวชี้วัดที่นับตัวนักเรียนใช้ร้อยละทั้งหมด และ**ขยับเพดานของข้อนักเรียนยากจนจาก 50% เป็น 100%**

เหตุผลของการขยับเพดาน: มัธยฐานของร้อยละนักเรียนยากจนคือ **60%** และ **62.3% ของโรงเรียนชนเพดาน 50% เดิม** ทำให้ข้อนี้กลายเป็นเพดานตัน — โรงเรียนที่ยากจน 50% กับ 100% ได้คะแนนเท่ากัน พอขยับเพดานเป็น 100% สัดส่วนที่ได้เต็มลดเหลือ 13.0% และ D เพิ่มจาก 0.35 เป็น 0.44
