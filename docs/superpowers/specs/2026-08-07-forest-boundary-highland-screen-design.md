## 1. เจตนา

นำ **แนวคิดการทับซ้อน (spatial overlay)** ระหว่างพิกัดโรงเรียนกับ **แนวเขตป่าไม้** มาใช้เป็นสัญญาณประกอบการ **ชี้วัดและคัดกรองโรงเรียนพื้นที่สูง** ในแอป พ.ส.ศ. — ไม่ใช่แทนความสูงจาก DEM หรือการเข้าถึงถนน แต่เป็น **ชั้นหลักฐานเชิงพื้นที่** ว่า “ที่ตั้งอยู่ใน/ชิดเขตป่า” ซึ่งในบริบทไทยมักสัมพันธ์กับพื้นที่สูง ถิ่นทุรกันดาร และการเข้าถึงยาก

**คำถามที่ชั้นนี้ตอบ:**  
โรงเรียนนี้อยู่ **ใน** / **ชิด** / **นอก** แนวเขตป่าประเภทใดบ้าง — และสัญญาณนั้นควรเข้า **ประตูคัดกรองพื้นที่สูง** หรือแค่ **หลักฐานประกอบ**?

## 2. ทำไมเขตป่าถึงเกี่ยวกับ “โรงเรียนพื้นที่สูง”

| เหตุผล | รายละเอียด |
|---|---|
| ความสัมพันธ์เชิงพื้นที่จริง | โรงเรียนบนดอย/หุบเขาภาคเหนือ–ตะวันตก–ใต้จำนวนมากตั้งในหรือชิด ป่าสงวนแห่งชาติ / อุทยาน / เขตรักษาพันธุ์ — เขตป่าเป็น proxy ของ “ถิ่นที่รัฐกำหนดพื้นที่อนุรักษ์” ไม่ใช่แค่ elev ≥ 500 ม. |
| ช่องว่างของเกณฑ์ความสูงอย่างเดียว | โรงเรียนหุบเขาต่ำกว่า 500 ม. แต่ถูกล้อมด้วยป่าเขา หรือโรงเรียนที่ราบสูงนอกเขตป่า — DEM + route อย่างเดียวอาจจัดกลุ่มผิดจากนิยามปฏิบัติของพื้นที่ |
| หลักฐานที่ผู้ตรวจเข้าใจ | แผนที่ทับเขตป่า + ชื่อเขต เป็นหลักฐานที่หน่วยงานคุ้น (กรมป่าไม้ / กรมอุทยาน ฯ) ใช้คู่กับภาพ 3 มิติได้ทันที |
| เติมแกน A (ภูมิประเทศ) โดยไม่ยุบแกน B/C | เขตป่า = สัญญาณ **ที่ตั้ง/การใช้ที่ดิน** ตั้งฉากกับ RCR/TTR (การเข้าถึง) และความหนาแน่นชุมชน — สอดคล้องหลัก 3 แกนใน RESEARCH |

**สิ่งที่เขตป่าไม่ใช่**

- ไม่ใช่คำนิยามกฎหมาย “พื้นที่สูง” ของ สพฐ./HRDI โดยตรง (นิยามหลักยังเป็น ภูเขา / ≥500 ม. / สูงกว่าค่าเฉลี่ยจังหวัด / หุบที่เส้นทางข้ามที่สูง)  
- ไม่ใช่คะแนน พ.ส.ศ. 100 โดยอัตโนมัติจนกว่าคณะกรรมการเกณฑ์จะรับ  
- ไม่ทดแทน `terrain-signature` หรือ `access-hardship` — เป็น **ชั้นเสริม**

## 3. นิยาม “ทับซ้อน” ที่ระบบต้องคำนวณ

ให้พิกัดโรงเรียน `(lat, lng)` (หมุดที่ตรวจแล้ว) เทียบกับ polygon เขตป่า:

| สถานะทับซ้อน | นิยามเชิงเรขาคณิต | ใช้ทำอะไร |
|---|---|---|
| **in** | จุดอยู่ใน polygon (รวมขอบ) ของเขตอย่างน้อย 1 แห่ง | สัญญาณแรง: อยู่ในเขตป่า |
| **near** | จุดอยู่นอกทุก polygon แต่ระยะตั้งฉากถึงขอบเขตใกล้สุด **≤ `FOREST_NEAR_M`** (ค่าเริ่มต้นเสนอ **1,000 ม.** — เท่า `SECTOR_RADIUS_M` / รัศมีวิเคราะห์ท้องถิ่น) | สัญญาณปานกลาง: ชิดแนวป่า |
| **out** | ห่างขอบเขตใกล้สุด > `FOREST_NEAR_M` | ไม่ใช้เป็นตัวดัน highland จากชั้นนี้ |
| **unknown** | ยังไม่มีชั้นข้อมูลใน bbox / โหลดล้มเหลว / แหล่งข้อมูลไม่ครอบคลุม | **ห้ามเดา out** — แสดง “ไม่มีข้อมูลเขตป่า” |

ผลต่อโรงเรียนหนึ่งแห่ง:

```ts
// ร่างชนิดข้อมูล — ยังไม่ implement
interface ForestOverlayResult {
  status: "in" | "near" | "out" | "unknown";
  nearestDistanceM: number | null;   // 0 เมื่อ in
  zones: Array<{
    name: string;                    // ชื่อเขต (ไทย)
    kind: ForestZoneKind;            // ดูด้านล่าง
    relation: "in" | "near";
    distanceM: number;               // 0 เมื่อ in
  }>;
  dataSource: string;                // แหล่ง + รุ่นปีที่เผยแพร่
  attribution: string;               // ข้อความ attribution บังคับแสดง
  calculatedAt: string;              // ISO
}

type ForestZoneKind =
  | "national_reserved_forest"   // ป่าสงวนแห่งชาติ
  | "national_park"              // อุทยานแห่งชาติ
  | "wildlife_sanctuary"         // เขตรักษาพันธุ์สัตว์ป่า
  | "non_hunting"                // เขตห้ามล่า
  | "other_protected"            // อื่นที่อยู่ในชั้นอนุรักษ์ (ระบุใน name)
  | "unclassified";
```

**กฎความซื่อสัตย์ของข้อมูล (copy จาก admin-boundaries):**

1. ไม่พบ polygon ใน bbox ≠ อยู่นอกเขตป่าทั่วประเทศ  
2. ห้ามวาดวงกลมสมมติแทนขอบเขตที่ไม่มี  
3. แสดง attribution แหล่งข้อมูลทุกครั้งที่เปิดชั้น  
4. จุดที่ไม่มีพิกัดโรงเรียนที่เชื่อถือได้ → ไม่รัน overlay

## 4. แหล่งข้อมูลที่เสนอ (เรียงตามความเหมาะใช้ราชการ)

| ลำดับ | แหล่ง | ข้อดี | ข้อควรระวัง |
|---|---|---|---|
| 1 (เป้า production) | ชั้นเขตป่า/อนุรักษ์จากหน่วยงานรัฐ (กรมป่าไม้ / กรมอุทยานแห่งชาติ สัตว์ป่า และพันธุ์พืช / เผยแพร่ผ่าน OneMap / GISTDA / ชุดข้อมูลเปิดของกระทรวง) | ตรงอำนาจประกาศเขต | ต้องตรวจสัญญาอนุญาตใช้, รุ่นปี, ระบบพิกัด (มัก TWD97 / UTM); อาจต้องแปลงเป็น WGS84 ก่อนใช้กับ Cesium |
| 2 (นำร่อง / fallback) | ชุดขอบเขตคุ้มครองที่เผยแพร่สาธารณะ (เช่น WDPA ผ่าน Protected Planet — มีพื้นที่ไทย) | โหลด/แปลงเป็น GeoJSON ได้, มี kind ระดับนานาชาติ | ชื่อไทยอาจไม่ครบ, ขอบเขตอาจไม่ตรงประกาศล่าสุดของไทย 100% |
| 3 (อ้างอิงภาพเท่านั้น) | OSM (`boundary=protected_area` / `protect_class` / ชื่ออุทยาน) ผ่าน Overpass รอบจุด | pattern เดียว admin overlay, ไม่ต้อง host ไฟล์ใหญ่ทั้งประเทศ | **ไม่ครบและไม่ใช่ชั้นทางการ** — ใช้แสดงผลได้ ห้ามใช้เป็นประตูคัดกรองเพียงลำพัง |

**ข้อเสนอเฟสข้อมูล**

- **เฟส 0 (เอกสารนี้):** ล็อกนิยาม in/near/out + จุดต่อระบบคัดกรอง  
- **เฟส 1 — overlay อ้างอิงบนแผนที่:** ชั้นเปิด/ปิด วาดแนวเขตรอบจุดวิเคราะห์ (pattern เดียวเทศบาล) — **ยังไม่ให้คะแนน ไม่บังคับประตู**  
- **เฟส 2 — สัญญาณคัดกรอง:** บันทึก `ForestOverlayResult` ใน `gis` (sanitize) ใช้เป็น **ประตูเสริม / ธง / หลักฐาน** ตามตาราง §5  
- **เฟส 3 (นโยบาย):** ถ้าคณะกรรมการรับ — ผูกเป็นเงื่อนไขประกาศหรือตัวชี้วัดอย่างเป็นทางการ (นอก scope แอปจนกว่าจะมีมติ)

## 5. เชื่อมเข้า “ระบบคัดกรองโรงเรียนพื้นที่สูง” ใน newssra

ระบบปัจจุบันคัด/จำแนกพื้นที่สูงหลายชั้นอยู่แล้ว — เขตป่าเป็น **อินพุตเพิ่ม** ไม่แทนชั้นเดิม

```
พิกัดโรงเรียน
    ├─ DEM / morphology / terrain-signature     → landform, highland, island
    ├─ เส้นทาง OSRM + elevation profile         → access, routeHigh, hardship 3.2
    ├─ อาคาร / density                          → ชุมชน ใหญ่/ชนบท
    ├─ เขตเทศบาล (overlay)                      → บริบทเมือง (อ้างอิง)
    └─ แนวเขตป่า (ใหม่)                         → in | near | out | unknown
              │
              ▼
     ประตู / ธง / หลักฐานพื้นที่สูง (§5.1–5.3)
```

### 5.1 บทบาทที่แนะนำ (ยังไม่ให้คะแนน 100 โดยตรง)

| บทบาท | พฤติกรรมที่เสนอ | โค้ด/จุดต่อ |
|---|---|---|
| **Overlay แผนที่** | Toggle “แนวเขตป่า” วาด polygon + ป้ายชื่อ; จุดโรงเรียนมี badge in/near | `CesiumMap` + โมดูล `lib/map/forestBoundaries.ts` (ใหม่) — mirror `adminBoundaries.ts` |
| **หลักฐานใน GisSummary** | แสดงสถานะ + รายชื่อเขต + ระยะใกล้สุด + แหล่งข้อมูล | `components/GisSummary.tsx` |
| **ธง validation (info)** | V-forest-in / V-forest-near เมื่อ in/near (โทน info — ไม่ block ส่ง) | `lib/gis-flags.ts` |
| **ประตูคัดกรองพื้นที่สูง (screening gate)** | ใช้เป็น **เงื่อนไขเสริม** ร่วม elevation gate ของ สพฐ. — ดู §5.2 | pure ใน `lib/` (เช่น `lib/highland-screen.ts` หรือขยาย community-class) |
| **ไม่ทำในเฟส 1–2** | ห้ามเขียนคะแนนเข้า indicator ใด ๆ; ห้ามแทนที่ `settingType`; ห้าม auto-submit | — |

### 5.2 ตรรกะประตูคัดกรองที่เสนอ (ร่าง — ต้องยืนยันนโยบายก่อนล็อก)

นิยามปฏิบัติ “เข้าข่ายพื้นที่สูงให้พิจารณาต่อ” (screening) ควรเป็น **OR หลายสัญญาณ** ไม่ใช่แค่ elev:

```
highlandScreenCandidate =
    elevGate                    // ALT ≥ 500 หรือ > provinceAvg หรือ route ข้ามที่สูง (ของเดิม)
    OR terrainHighland          // terrain-signature กลุ่มภูเขา/หุบ/ที่ราบสูง
    OR forestIn                 // หมุด in เขตป่า (เฟส 2 + แหล่งข้อมูลทางการ)
    OR (forestNear AND (elevGate OR terrainHighland OR accessSev ≥ 2))
```

| สัญญาณ | ความหมายในการคัดกรอง |
|---|---|
| `forestIn` | อยู่ในเขตป่า → ผ่านประตู “ตั้งในพื้นที่อนุรักษ์/ป่า” ให้เข้าคิวประเมินพื้นที่สูง/ทุรกันดาร แม้ elev ก้ำกึ่ง (ยังต้องได้คะแนนด้านอื่นตามเกณฑ์) |
| `forestNear` อย่างเดียว | **ไม่พอ** ผ่านประตูคนเดียว — ต้องคู่ elev/terrain/access เพื่อกันโรงเรียนชิดขอบป่าชานเมือง |
| `forest out` + elev ต่ำ + terrain ราบ | ไม่ดันเข้ากลุ่มพื้นที่สูงจากชั้นนี้ |
| `unknown` | ไม่ตัดสิทธิ์ ไม่ผ่านประตูจากชั้นป่า — ใช้ชั้น DEM/เส้นทางตามเดิม |

**เกาะ:** เขตป่าชายเลน/ป่าเกาะ อาจ `in` ได้ — **ไม่แปลงเป็น highland_remote อัตโนมัติ**; คงกลุ่ม `island` ตาม terrain-signature แล้วแสดง forest เป็นหลักฐานประกอบเท่านั้น

### 5.3 ความสัมพันธ์กับข้อ 3.2 (access-hardship)

- เขตป่า **ไม่ใช่** input ตรงของต้นไม้ 5 ระดับ 3.2  
- ถ้าต้องการในอนาคต: ใช้ได้แค่ใน `evidence[]` หรือ `reviewFlags` (“ตั้งในเขตป่าสงวน…”) เมื่อ `nearBoundary`  
- การ “ยากลำบาก” ยังวัดจาก RCR/TTR/ความเร็ว/gain + ชุมชน + ซับซ้อนของภูเขา ตามสเปก access-hardship

### 5.4 บันทึกใน state (เฟส 2)

```ts
// บน GisAnalysis — optional; แถวเก่าไม่มี key นี้
forestOverlay?: ForestOverlayResult;
```

- Server-owned หลัง sanitize (เหมือน `sectorElevations` / `accessHardship`)  
- Client ส่ง geometry ดิบไม่ได้ — ส่งพิกัดหมุด; server (หรือ pipeline ที่เชื่อถือได้) เป็นผู้คำนวณทับซ้อนเมื่อมีชั้นทางการ  
- เฟส 1 overlay-only: ยังไม่บังคับเก็บใน DB ก็ได้ (คำนวณตอนเปิด toggle)

## 6. สถาปัตยกรรม implement ที่สอดคล้อง repo

### 6.1 เฟส 1 — overlay อ้างอิง (mirror เทศบาล)

| ชิ้น | รายละเอียด |
|---|---|
| `lib/map/forestBoundaries.ts` | client-safe; `fetchForestBoundaries(lat,lng,radiusM)`; `pointInForestZones`; parse/validate rings (finite, ≥4 จุด) |
| รัศมีดึงข้อมูล | เสนอ `FOREST_FETCH_RADIUS_M = 15_000` (เท่า admin) — วาดรอบจุดวิเคราะห์ ไม่ precompute ทั้ง ปท. ในเฟสแรก |
| `CesiumMap` | datasource `forest`; toggle; สีแยก kind; clampToGround; attribution |
| เทสต์ | parse GeoJSON/Overpass; point-in-polygon บน fixture เล็ก; ระยะ near ขอบ |

### 6.2 เฟส 2 — คัดกรอง + บันทึก

| ชิ้น | รายละเอียด |
|---|---|
| ชั้นข้อมูลทางการ | ไฟล์/ตารางที่แปลงแล้ว (เช่น per-province หรือ spatial index) — **อย่า** ยิง Overpass เป็นประตูคะแนน |
| pure `classifyForestOverlay(point, zones)` | unit-test ได้โดยไม่พึ่ง Cesium |
| `highlandScreen` pure | รวม elevGate + terrain + forest ตาม §5.2 |
| `sanitizeGis` | allowlist `forestOverlay` |
| ธง V-series | info เมื่อ in/near; ไม่ block |
| Dashboard / list (ทางเลือก) | กรอง “ในเขตป่า” สำหรับ admin — หลังมี summary column |

### 6.3 สิ่งที่ห้าม

- ใช้ OSM เพียงแหล่งเดียวแล้วตัดสิทธิ์หรือให้คะแนน  
- ถือว่า “ไม่พบเขตใน Overpass = ไม่อยู่ในป่า”  
- ยุบ forest + density + RCR เป็นเลขเดียวโดยไม่ผ่านมติเกณฑ์  
- เก็บ geometry เขตทั้งประเทศใน `state` JSON ของ assessment (เก็บแค่ผลทับซ้อน + metadata)

---

## 7. ค่าคงที่เสนอ (ล็อกตอน implement)

```
FOREST_NEAR_M              = 1000   // ชิดแนวป่า
FOREST_FETCH_RADIUS_M      = 15000  // ดึง/วาดรอบจุด
FOREST_OVERLAY_VERSION     = "fo-1"
// ชนิดเขต: national_reserved_forest | national_park | wildlife_sanctuary | non_hunting | other_protected
```

เปลี่ยน `FOREST_NEAR_M` ต้องมี boundary test (999 / 1000 / 1001 ม.)

## 8. แผนทดสอบ (เมื่อลงมือ)

| กลุ่ม | เคส |
|---|---|
| in | จุดใน polygon → status in, distance 0 |
| near | จุดนอก ระยะ 500 ม. → near; 1000 ม. → near; 1001 → out |
| multi-zone | ทับ 2 เขต → zones[] ครบ เรียง distance |
| unknown | ไม่มีชั้นใน bbox → unknown ไม่ใช่ out |
| island | in ป่าชายเลน → ไม่บังคับ highland group |
| screen | elev ต่ำ + forestIn + แหล่งทางการ → candidate; forestNear อย่างเดียว → ไม่ผ่าน |
| UI | toggle ปิดไม่ยิง fetch ซ้ำเกิน cache; attribution โชว์เมื่อเปิดชั้น |

## 9. ความเสี่ยงและข้อกฎหมาย/ข้อมูล

1. **ความถูกต้องของขอบเขต** — ประกาศเขตเปลี่ยนได้; ต้องระบุปีที่ชั้นข้อมูลและช่องอัปเดต  
2. **สิทธิการใช้ข้อมูล** — ตรวจ license ก่อน commit ไฟล์ geo เข้า repo; ถ้าห้าม redistrib ให้โหลดตอน runtime จากแหล่งที่อนุญาต  
3. **False positive ชานเมือง** — บางเขตป่า/พื้นที่สีเขียวชิดเมือง → บังคับคู่ near กับ elev/terrain/access  
4. **False negative** — โรงเรียนทุรกันดารนอกแนวป่า (ไร่หมุนเวียน / ดอยนอกเขต) ยังพึ่ง DEM + เส้นทาง  
5. **พิกัดหมุดผิด** — overlay ผิดตามหมุด; ต้องยืนยันหมุดก่อน (flow ลากหมุดมีอยู่แล้ว)

## 10. ลำดับงานส่งต่อทีม implement

1. ยืนยันแหล่งชั้นเขตป่า production (หน่วยงาน + รูปแบบไฟล์ + license)  
2. เฟส 1: overlay บน `/map` + เอกสาร attribution  
3. pure geometry + เทสต์ in/near/out  
4. เฟส 2: บันทึก `gis.forestOverlay` + ธง info + ข้อความใน GisSummary  
5. ผูก `highlandScreenCandidate` (§5.2) หลังยืนยันนโยบายประตู  
6. (นโยบาย) ถ้าจะให้คะแนนหรือเป็นเงื่อนไขประกาศ — อัปเดตเกณฑ์ v1 / CLAUDE domain rules แยก PR

## 11. สรุปหนึ่งย่อหน้าสำหรับ handoff

ระบบคัดกรองโรงเรียนพื้นที่สูงของ newssra ควรรับ **แนวเขตป่าไม้เป็นชั้นทับซ้อนพิกัดโรงเรียน** โดยคำนวณสถานะ in / near (≤1 กม.) / out / unknown แสดงเป็น overlay บนแผนที่ 3 มิติและหลักฐานใน GisSummary ก่อน แล้วจึงใช้ `in` (และ `near` ร่วม elev/terrain/access) เป็น **ประตูคัดกรองเสริม** คู่กับเกณฑ์ความสูง สพฐ. และ terrain-signature — ไม่ยุบเข้าคะแนน 100 และไม่ใช้ OSM เป็นแหล่งตัดสินเพียงลำพังจนกว่าจะมีชั้นทางการและมตินโยบาย

## 12. ช่องว่างที่เอกสารนี้ปิด / ยังเปิด

| ปิดแล้วในเอกสารนี้ | ยังเปิด (ต้องมติภายนอก) |
|---|---|
| นิยาม in/near/out/unknown | แหล่งข้อมูลทางการ + license ที่ใช้ production |
| จุดต่อ terrain / 3.2 / community | จะให้ forestIn ผ่านประตูโดยไม่ต้อง elev หรือไม่ |
| เฟส overlay → สัญญาณ → นโยบาย | น้ำหนักคะแนน (ถ้ามี) ในเกณฑ์ 2569+ |
| ห้ามเดาเมื่อไม่มีข้อมูล | ค่า FOREST_NEAR_M สุดท้าย (1 กม. เป็นค่าเริ่มต้น) |
