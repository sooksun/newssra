# Cesium Map Panel Collapse Design

Date: 2026-07-22

## Goal

เพิ่มพื้นที่มองเห็นแผนที่ Cesium โดยให้ผู้ใช้ซ่อนแผงข้อมูลด้านซ้ายทั้งหมดและเปิดกลับได้ทันที โดยไม่เปลี่ยนข้อมูล การคำนวณ หรือสถานะการทำงานภายในแผง

## Interaction

- เมื่อเปิดหน้า `/map` แผงข้อมูลแสดงตามปกติ
- ปุ่ม “ย่อแผงข้อมูล” อยู่มุมขวาบนของหัวแผงและไม่ทับชื่อแผง
- เมื่อกดปุ่มย่อ แผงข้อมูลทั้งหมดจะถูกซ่อน และมีปุ่มลอยขนาดไม่น้อยกว่า 44 × 44 พิกเซลที่มุมซ้ายบนของแผนที่
- เมื่อกดปุ่มลอย “ขยายแผงข้อมูล” แผงเดิมจะแสดงอีกครั้งโดยข้อมูลและสถานะภายในไม่เปลี่ยน
- เมื่อรีเฟรชหรือเข้า `/map` ใหม่ แผงเริ่มต้นในสถานะขยาย

## Accessibility

- ปุ่มทั้งสองเป็น `<button type="button">` และใช้งานด้วยคีย์บอร์ดได้
- ใช้ `aria-expanded` เพื่อสื่อสถานะ และ `aria-controls` เชื่อมกับแผงข้อมูล
- ปุ่มมี `aria-label` และ `title` ภาษาไทยที่อธิบายการกระทำชัดเจน
- มี focus style ที่มองเห็นได้ และพื้นที่กดไม่น้อยกว่า 44 × 44 พิกเซล

## Responsive Behavior

- เดสก์ท็อป: ปุ่มเปิดกลับอยู่ตำแหน่งเดียวกับมุมซ้ายบนของแผงเดิม เพื่อคืนพื้นที่แผนที่เกือบทั้งหมด
- หน้าจอแคบ: ปุ่มยังอยู่ในขอบเขตแผนที่และไม่ชนเข็มทิศซึ่งอยู่ด้านขวา
- การย่อหรือขยายแผงไม่เปลี่ยนขนาด canvas และไม่สร้าง Cesium viewer ใหม่

## Implementation Boundary

- เก็บสถานะย่อ/ขยายแบบ local state ภายใน `components/map/CesiumMap.tsx`
- เพิ่ม class สำหรับหัวแผง ปุ่มย่อ และปุ่มเปิดกลับใน `app/globals.css`
- ไม่ใช้ `localStorage` และไม่บันทึกสถานะข้ามการรีเฟรช
- ไม่แก้ logic ของแนวชายแดน การค้นหา เส้นทาง GIS อาคาร หรือการประเมิน
- รักษาการแก้ไขที่มีอยู่แล้วในไฟล์ `CesiumMap.tsx` และ `globals.css`

## Verification

- เพิ่ม regression test ที่ตรวจ contract ของปุ่มย่อ/ขยายและสถานะ accessibility โดยให้ test ล้มเหลวก่อนเพิ่ม implementation
- รัน unit tests ทั้งชุดและ production build
- ตรวจหน้า `/map` จริงในเบราว์เซอร์: ย่อแผง ขยายกลับ ตรวจว่าข้อมูลเดิมยังอยู่ และตรวจ viewport เดสก์ท็อปกับมือถือ

## Acceptance Criteria

1. แผงข้อมูลแสดงเมื่อเปิดหน้าใหม่
2. กดปุ่มย่อแล้วแผงทั้งหมดหายไปและพื้นที่แผนที่เปิดกว้างขึ้น
3. มีปุ่มลอยขนาดแตะได้ง่ายสำหรับขยายแผงกลับ
4. กดขยายแล้วแผงและข้อมูลเดิมกลับมา
5. ใช้งานปุ่มด้วยคีย์บอร์ดและโปรแกรมอ่านหน้าจอได้
6. ฟังก์ชัน Cesium และ GIS เดิมยังทำงาน และ build ผ่าน
