# Cesium Route Elevation Flags Design

Date: 2026-07-22

## Goal

แสดงธงสีแดง 2 จุดบนแผนที่ Cesium ในโหมดโรงเรียน เพื่อให้ผู้ใช้เห็นระดับความสูงของจุดที่ตั้งโรงเรียนและตำแหน่งที่สูงที่สุดบนเส้นทางรถยนต์ที่เลือกจากศาลากลางจังหวัดมายังโรงเรียนได้ทันที

## Confirmed Meaning of the Two Flags

1. **ที่ตั้งโรงเรียน** — ใช้พิกัด `center` ปัจจุบัน รวมถึงพิกัดใหม่หลังผู้ใช้ค้นหาหรือลากหมุด
2. **จุดสูงสุดบนเส้นทาง** — ใช้จุดตัวอย่างที่มีระดับความสูงมากที่สุดบนเส้นทาง OSRM ที่ผู้ใช้เลือกอยู่ ไม่ใช่จุดสูงสุดภายในพื้นที่รอบโรงเรียน และไม่ใช่จุดสูงสุดจากเส้นทางทางเลือกทุกเส้นรวมกัน

หมุดสีน้ำเงินของศาลากลางจังหวัดยังคงอยู่เพื่อบอกจุดเริ่มต้นของเส้นทาง

## Selected Approach

ใช้ชุดตัวอย่างภูมิประเทศของเส้นทางที่เลือกจำนวนไม่เกิน 120 จุด กระจายสม่ำเสมอตลอดเส้นทาง โดยบังคับให้มีทั้งพิกัดเริ่มต้นและพิกัดปลายทาง จากนั้นจับคู่พิกัดแต่ละจุดกับค่าความสูงที่ Cesium terrain คืนมา

แนวทางนี้สมดุลระหว่างความละเอียดกับจำนวนคำขอ terrain และสอดคล้องกับจำนวนตัวอย่างที่ระบบใช้คำนวณความสูงสะสมของเส้นทางอยู่แล้ว การอ่านทุก vertex ของ OSRM ถูกตัดออกเพราะอาจสร้างภาระมากเกินไป ส่วนการใช้ค่าสูงสุดจากกริดรอบโรงเรียนถูกตัดออกเพราะไม่รับประกันว่าจุดนั้นอยู่บนเส้นทาง

คำว่า “จุดสูงสุด” ในหน้าจอจึงหมายถึง **จุดสูงสุดจากตัวอย่างบนแนวเส้นทางที่เลือก** ซึ่งเป็นค่าประมาณจากข้อมูล terrain ไม่ใช่การสำรวจระดับภาคสนาม

## Architecture and Data Flow

- เพิ่ม pure helper สำหรับลดจำนวนพิกัดเส้นทางโดยคงจุดแรกและจุดสุดท้าย และสำหรับเลือกพิกัดที่มีค่าความสูง finite สูงสุดจากชุดตัวอย่าง
- เมื่อ terrain พร้อม เส้นทางโหลดสำเร็จ หรือผู้ใช้เปลี่ยนเส้นทาง ระบบจะสุ่มค่าความสูงของเส้นทางที่เลือกใหม่
- ผลลัพธ์เดียวกันใช้คำนวณ:
  - ระดับความสูงของโรงเรียนจากพิกัดปลายทางที่รวมไว้แน่นอน
  - พิกัดและระดับความสูงสูงสุดบนเส้นทาง
  - ค่าความสูงสะสมขึ้น/ลงที่ระบบ GIS ใช้อยู่ เพื่อลดการยิง terrain ซ้ำใน assessment mode
- เก็บผลโปรไฟล์เส้นทางใน state ที่ผูกกับเส้นทางปัจจุบัน และยกเลิกผล async เก่าเมื่อพิกัดโรงเรียนหรือเส้นทางเปลี่ยน เพื่อไม่ให้ธงจากเส้นทางเดิมกลับมาทับผลใหม่
- การคำนวณภูมิสัณฐานเดิมใน `runAnalysis` ยังคงเป็นอิสระเพื่อไม่ขยายขอบเขตการแก้ไขเกินฟีเจอร์นี้

## Map Presentation

- เปลี่ยนหมุดโรงเรียนจากจุดแดงเป็น billboard รูปธงแดง โดยคง entity id `center-pin` เพื่อให้การลากหมุดเดิมยังทำงาน
- ป้ายโรงเรียนแสดงชื่อโรงเรียนและ `ระดับความสูง: N ม.` ปัดเป็นจำนวนเต็ม
- เพิ่ม billboard รูปธงแดงที่พิกัดตัวอย่างสูงสุดบนเส้นทาง พร้อมป้าย `จุดสูงสุดบนเส้นทาง: N ม.`
- ธงทั้งสองแนบพื้นภูมิประเทศ ใช้พื้นหลังป้ายสีแดงเข้ม ตัวอักษรสีขาว และไม่ถูก terrain บังเมื่อมองจากมุมกล้องปัจจุบัน
- เมื่อเลือกเส้นทาง 1/2/3 ธงจุดสูงสุดและตัวเลขจะย้ายตามเส้นทางที่เลือกโดยอัตโนมัติ
- ในมุมมองทั้งประเทศจะไม่แสดงธงทั้งสอง เช่นเดียวกับพฤติกรรมหมุดโรงเรียนปัจจุบัน

## Loading and Failure Behavior

- ธงโรงเรียนแสดงทันที และระหว่างรอ terrain ให้ป้ายระบุว่ากำลังอ่านระดับความสูง
- ธงจุดสูงสุดแสดงเมื่อได้เส้นทางและค่าความสูงที่ใช้งานได้แล้วเท่านั้น
- หากโหลดเส้นทางไม่สำเร็จ จะไม่มีธงจุดสูงสุดและใช้ข้อความผิดพลาดของเส้นทางเดิม
- หาก terrain ล้มเหลวหรือค่าทั้งหมดเป็น `NaN` ธงโรงเรียนยังอยู่แต่ระบุว่าไม่พบข้อมูลระดับความสูง และไม่สร้างธงจุดสูงสุดจากค่าปลอม เช่น `0 ม.`

## Testing

- เขียน unit test ก่อน implementation สำหรับการลดพิกัดโดยคง endpoints
- เขียน unit test สำหรับการจับคู่พิกัดกับความสูงสูงสุด การข้าม `NaN` และกรณีไม่มีค่าที่ใช้ได้
- เพิ่ม regression test ยืนยันว่า entity โรงเรียนยังใช้ `center-pin`, มีธงแดงสองบทบาท และ label แสดงระดับความสูง
- รัน test เฉพาะฟีเจอร์ให้เห็น RED ก่อน แล้วทำ GREEN
- รัน unit tests ทั้งชุด, TypeScript/production build และตรวจ `git diff --check`
- ตรวจหน้า `/map` จริงในเบราว์เซอร์ว่าเห็นธง 2 จุด ตัวเลขความสูง เปลี่ยนเส้นทางแล้วธงย้าย และยังลากธงโรงเรียนได้

## Acceptance Criteria

1. เมื่อเส้นทางและ terrain พร้อม แผนที่แสดงธงแดงที่โรงเรียนและธงแดงที่จุดตัวอย่างสูงสุดของเส้นทางที่เลือก
2. ป้ายของธงทั้งสองแสดงระดับความสูงเป็นเมตรอย่างชัดเจน
3. หมุดศาลากลางจังหวัดสีน้ำเงินและเส้นทางเดิมยังแสดงตามปกติ
4. การเลือกเส้นทางอื่นคำนวณพิกัดจุดสูงสุดใหม่และย้ายธงให้ตรงกับเส้นทางนั้น
5. การลาก/ย้ายจุดโรงเรียนยังทำงาน เพราะธงโรงเรียนคง id `center-pin`
6. ระบบไม่แสดง `0 ม.` แทนข้อมูล terrain ที่ล้มเหลว และไม่ใช้จุดสูงสุดนอกแนวเส้นทาง
7. ฟังก์ชันย่อ/ขยายแผง ขอบเขตประเทศ GIS และการวิเคราะห์เดิมไม่ถดถอย
